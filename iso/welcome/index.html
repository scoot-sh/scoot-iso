Welcome to scoot

A lightweight, fast and beautiful scrolling-tiling Wayland compositor that runs without a GPU.

Install scoot

Graphical install

Click the Install icon on the desktop (Calamares), pick scoot on the Desktop page, and reboot into it.

From a terminal

On this live session, the installer is already on your PATH:

sudo calamares

The installed system boots to a ReGreet login screen — it never autologins. Your live session's autologin exists only on this ISO.

Essential keys

The full default map ships in the installed docs; these are the ones to learn first. The super key is usually the OS/Windows key.

super + ReturnOpen a terminal
super + h j k lFocus column left / window down / window up / column right
super + shift + h j k lMove the focused column or window
super + rCycle the focused column's width
super + fToggle fullscreen
super + qClose the focused window
super + 1 … 9Jump to workspace 1–9 (shift moves the window with you)
super + comma / periodFocus output 1 / 2
super + shift + eQuit the session

Try it

Open windows

Press super + Return a few times: each terminal lands in a scrolling column. super + h/l scrolls between them.

Ask the compositor

Everything scriptable goes through IPC:

scoot msg --help

Change the look

This session wears vinyl-sunset. The installed system can switch to music-desk or radial-burst with one option:

desktop.look = "music-desk";
